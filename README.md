# Пикми

Пикми — menu bar-приложение для macOS с кастомным курсором, звуком клика и режимом презентации.

## Возможности

- шесть вариантов курсора и три крупных размера;
- скрытие штатного указателя, пока Пикми включён;
- анимация «тычка» и звук клика;
- эффект на быстрых повторных кликах;
- режим презентации: клики не передаются приложениям, а `Space` + drag остаётся доступным для Figma;
- горячие клавиши: `Control + Option + P` — включить/выключить курсор, `Control + Option + L` — режим презентации.

## Установка

1. Скачайте `Пикми.zip` из [Releases](../../releases).
2. Распакуйте `Пикми.app` и переместите его в «Программы».
3. При первом запуске macOS может попросить открыть приложение через контекстное меню Finder: нажмите правой кнопкой по приложению → «Открыть».
4. Для режима презентации разрешите Пикми в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».

Пикми использует недокументированные системные механизмы macOS для подмены курсора. Это личный эксперимент: новые версии macOS могут менять его поведение.

## Сборка

Требуются Apple Command Line Tools. Собрать universal-приложение для Apple Silicon и Intel можно так:

```bash
./scripts/package_app.sh
```

Результат: `dist/Пикми.app`.
