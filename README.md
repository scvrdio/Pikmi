# Пикми

Пикми — палочка для показа макетов, кода и других скучных картинок

## Возможности

- 6 вариантов курсора и три размера
- скрытие штатного указателя, пока Пикми включён
- анимация «тычка» и звук клика
- режим презентации: клики не передаются приложениям
- горячие клавиши: `Control + Option + P` — включить/выключить курсор, `Control + Option + L` — режим презентации.

## Установка

1. Скачай `Пикми.zip` из [Releases](../../releases).
2. Распакуй `Пикми.app` и перемести его в «Программы».
3. При первом запуске macOS может попросить открыть приложение через контекстное меню Finder: нажми правой кнопкой по приложению → «Открыть».
4. Для режима презентации разреши Пикми в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».

Пикми использует недокументированные системные механизмы macOS для подмены курсора. Это личный эксперимент: новые версии macOS могут менять его поведение.

## Сборка

Требуются Apple Command Line Tools. Собрать universal-приложение для Apple Silicon и Intel можно так:

```bash
./scripts/package_app.sh
```

Результат: `dist/Пикми.app`.
